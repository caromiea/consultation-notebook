# Consultation Notebook

A phone-friendly consultation booking and student attendance app. No ChatGPT subscription, API key, server, or build step is required.

## Publish on GitHub Pages

Upload index.html, app.js, style.css, and .nojekyll to the root of a dedicated repository. In Settings → Pages, choose Deploy from a branch, main, / (root), then Save. Use the published HTTPS address on your phone and add it to your Home Screen.

The app and its source are public when hosted using a free public GitHub repository. No student records or backup files belong in this repository.

## Transfer existing records

On the device and browser containing your records, open the old app and choose Export backup. Save that JSON file privately. Open the newly published app in the browser you intend to use on your phone, choose Restore backup, and select the file. Check the session count and attendance report before relying on the new app. Do not delete the old copy or backup until you have verified the transfer.

Records remain in local browser storage and do not sync across browsers or devices. Clearing browser data may remove records; export backups regularly. Each website address has separate storage.

Calendar exports are separate copies. Changes to a consultation do not automatically update calendar events. Import the .ics event for a five-minute reminder; reminder delivery depends on calendar settings and permissions.
